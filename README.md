# 👑 Crownie - Discord Chat Rewards Platform

Crownie is a web application that rewards Discord users with reputation points for active participation in chat. It connects Discord with a Django backend to track user activity, award points, and provide gamified incentives for community engagement.

## ✨ Features

### 🎮 Discord Integration
- **Real-time message tracking** in Discord channels
- **Automated session detection** (5+ minutes = points!)
- **Smart reputation system** based on chat activity
- **Quest system** with progress tracking
- **Leaderboards** to showcase top community members

### 🏆 Reward System
- **Points per minute** of active chatting
- **Activity bonuses** for message frequency
- **Session-based rewards** with minimum thresholds
- **Reputation leveling** system
- **Daily/Weekly bonuses**

### 📊 User Dashboard
- **Personal statistics** tracking
- **Quest progress** visualization
- **Reputation history** timeline
- **Achievement system**
- **Rank comparisons**

## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- PostgreSQL ( SQLite for development)
- Discord Bot Token
- Discord Server with appropriate permissions
